# 14 — MVP Development Phases & Acceptance Criteria

---

## Phase 1 — Foundation

Build:
- Project setup
- Auth
- Database schema
- App shell
- Landing page
- Onboarding
- Profile and targets

---

## Phase 2 — Meal Upload

Build:
- Upload UI
- Image storage
- Meal draft creation
- AI analysis job
- Analysis loader
- Result screen
- Confirm/edit flow

---

## Phase 3 — Dashboard

Build:
- Daily dashboard
- Meal cards
- Macro progress
- Calorie ring
- Water tracker
- Daily insight card

---

## Phase 4 — Diary & Analytics

Build:
- Meal history
- Meal detail page
- Weekly analytics
- Monthly analytics
- Charts and heatmap

---

## Phase 5 — Polish

Build:
- Empty states
- Loading states
- Mobile responsive polish
- Error handling
- Better AI prompts
- Nutrition confidence UI
- Final design cleanup

---

## MVP Acceptance Criteria

The MVP is complete when:

1. User can register/login.
2. User can complete onboarding.
3. User can upload a meal photo.
4. AI returns food estimate.
5. User can edit estimate.
6. User can save meal.
7. Dashboard updates immediately.
8. User can view daily meals.
9. User can view weekly/monthly analytics.
10. App is responsive and works well on mobile browser.
11. UI feels clean, abstract, and simple.
12. AI results are clearly labeled as estimates.
13. Backend protects user data.
14. Images are stored properly.
15. Codebase is ready for future mobile app migration.
