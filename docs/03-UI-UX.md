# 03 — UI / UX Direction

The uploaded reference image shows a nutrition app with:
- Card-based layout
- Rounded corners
- Soft colors
- Food illustration/photo area
- Macro progress bars
- Clean mobile-like interface

For this project, create a webapp UI inspired by that simplicity, but **more abstract and modern**.

---

## Visual Style

### Use:
- Abstract food-inspired shapes
- Soft gradients
- Rounded cards
- Floating panels
- Minimal icons
- Light background
- High whitespace
- Premium SaaS-like polish
- Mobile-first responsive layout

### Avoid:
- Generic admin dashboard look
- Too many tables
- Dark heavy fitness style
- Overly childish food illustrations
- Cluttered calorie-counting UI

---

## Design Keywords

- Abstract nutrition dashboard
- Soft glass cards
- Organic shapes
- Calm green, orange, cream, yellow accents
- Rounded 2xl cards
- Clean progress rings
- Minimal typography
- Friendly premium wellness aesthetic
- Webapp that feels mobile-ready

## Typography

Use a clean modern font:
- Inter
- Geist
- Manrope
- Plus Jakarta Sans

> **Recommended:** Use **Geist** or **Inter**.

---

## Layout Principles

### Mobile-first
- The app should look excellent at **390px** width.
- Desktop should use a centered app shell, not a stretched huge dashboard.

### Desktop layout
- Left navigation
- Center daily feed
- Right nutrition summary

### Mobile layout
- Bottom navigation
- Floating upload button
- Simple stacked cards

---

## Cross-Cutting UI States

Every screen must implement:
- **Loading** state (skeleton or animated placeholder)
- **Empty** state (illustration + CTA)
- **Error** state (clear message + retry)
- **Success** state (confirmation feedback)

---

## Tone in Microcopy

- Encouraging, never judgmental
- Use second person ("you")
- Avoid diet jargon and shame language
- Always frame estimates as estimates ("approximately", "estimated")
- Reinforce that data is private and editable
