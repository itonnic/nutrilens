# 01 — Product: Positioning, Users, MVP & Future Scope

## Product Positioning

This is **NOT** a hardcore bodybuilding macro tracker at first.

### It should feel more like:
> "A visual food diary that helps normal people understand what they eat without manually entering everything."

### Target Users
- People trying to lose weight
- People trying to maintain healthy eating
- Busy professionals
- Beginners who hate manual calorie tracking
- People who want visual daily/weekly/monthly insight
- Users who want lightweight guidance, not strict dieting

### Tone
- Clean
- Encouraging
- Non-judgmental
- Visual
- Friendly but not childish
- Abstract and modern

### Avoid
- Overly medical tone
- Shame-based messaging
- Aggressive diet culture
- Complicated bodybuilding UX
- Too many numbers on one screen

---

## MVP Scope

Build a fully functional webapp MVP. The MVP must include all the following:

### 1. Authentication
- Email/password login
- Google OAuth optional but recommended
- User profile
- Nutrition goal setup

### 2. Onboarding
A simple first-time setup flow:

**Step 1 — Basic info:**
- Age
- Gender (optional)
- Height
- Weight
- Activity level

**Step 2 — Goal:**
- Lose weight
- Maintain weight
- Gain weight
- Eat healthier

**Step 3 — Target speed:**
- Slow
- Balanced
- Aggressive

**Step 4 — Dietary preferences:**
- None
- Vegetarian
- Vegan
- Low carb
- High protein
- Gluten free
- Lactose free
- Custom notes

**Step 5 — Targets:**
- App calculates suggested daily targets:
  - Calories
  - Protein
  - Carbs
  - Fat
  - Fiber
  - Water
- Allow user to manually override targets.

### 3. Meal Upload

User can upload a food photo from:
- File input
- Drag and drop
- Mobile browser camera capture using file input
- Optional paste image

**Flow:**
1. User uploads image.
2. Image preview appears.
3. User selects meal type:
   - Breakfast
   - Lunch
   - Dinner
   - Snack
   - Drink
4. User optionally adds text:
   - "This was homemade"
   - "There were 2 eggs"
   - "No sauce"
   - "Half portion"
5. AI analyzes image.
6. Results screen appears.
7. User confirms or edits.
8. Meal is saved to daily log.

### 4. AI Food Analysis

The AI should return structured JSON with:
- `detected_items`
- `estimated_portion`
- `calories`
- `macros`
- `micronutrients` if available
- `confidence`
- `assumptions`
- `user_editable_fields`
- `warnings`

> **Important:** AI estimation must be presented as an estimate, not medical truth.

### 5. Manual Correction

Users must be able to edit:
- Food name
- Quantity
- Unit
- Calories
- Protein
- Carbs
- Fat
- Fiber
- Sugar
- Sodium

> Because image-based nutrition estimation will never be perfect.

### 6. Daily Dashboard
The dashboard should show:
- Current date
- Daily calorie target
- Calories consumed
- Calories remaining
- Protein progress
- Carbs progress
- Fat progress
- Fiber progress
- Water progress
- Meal cards
- Health score / nutrition balance score
- Quick upload button

### 7. Weekly View
Show:
- Weekly calorie average
- Protein average
- Macro balance
- Best day
- Highest calorie day
- Missed tracking days
- Simple chart
- Weekly insight generated by AI

### 8. Monthly View
Show:
- Calendar heatmap
- Average daily calories
- Average protein
- Weight trend if user enters weight
- Goal consistency
- Top repeated foods
- Monthly AI summary

### 9. Food Diary
A chronological list of all saved meals:
- Date
- Meal type
- Image thumbnail
- Food title
- Calories
- Macro summary
- Edit/delete actions

### 10. Nutrition Detail Page
For each meal:
- Full image
- Detected items
- Nutrition breakdown
- AI assumptions
- Confidence
- Corrections history (optional)
- "Improve estimate" action

### 11. Profile & Goals
User can update:
- Weight
- Goal
- Daily calorie target
- Macro targets
- Dietary preferences
- Units: metric / imperial
- Theme preference (optional)

## Future Scope

Design the codebase so these can be added later:

### Mobile App
The webapp should be built in a way that can later become:
- PWA
- React Native app
- Expo app
- Capacitor-wrapped app

> Use shared business logic wherever possible.

### Barcode Scanner
- Scan packaged food barcode
- Match against nutrition database
- Add to diary

### Recipe Builder
- User uploads multiple ingredients
- App calculates total recipe nutrition
- User divides by serving count

### Meal Recommendations
- "You are low on protein today"
- "Suggested dinner: high protein, low calorie"
- "You exceeded sodium this week"

### Coach Mode
- AI nutrition coach chat
- Weekly plan
- Habit suggestions
- Personalized insights

### Wearable Integrations
- Apple Health
- Google Fit
- Garmin
- Fitbit

### Water Tracking
- MVP can include simple manual water tracking.
- Future can include reminders.

### Weight Tracking
- MVP can include manual weight entries.
- Future can include chart + trend projection.

### Social / Partner Features
- Share weekly report
- Invite nutritionist
- Family mode
- Coach dashboard
