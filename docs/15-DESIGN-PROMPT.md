# 15 — Design Prompt for UI Generation

> Drop-in prompt for visual UI generation tools (Magic, v0, Figma AI, etc.).

---

## Prompt

Design a modern AI nutrition tracking webapp called **NutriLens**.

The app is a mobile-first webapp where users upload meal photos and AI estimates calories, macros, and nutrition values. The visual style should be abstract, soft, clean, and premium.

### Use
- Warm off-white background
- White rounded cards
- Organic abstract gradient shapes
- Green, orange, yellow, purple accents
- Large rounded nutrition cards
- Progress rings and bars
- Minimal food illustrations or image thumbnails
- Soft shadows
- Calm wellness feeling

### Do not use
- Generic admin dashboard style
- Dark gym app style
- Overly complex tables
- Aggressive diet visuals
- Too much text

### Create screens

1. Landing page
2. Onboarding flow
3. Today dashboard
4. Meal upload screen
5. AI analyzing state
6. Meal analysis result
7. Meal detail page
8. Weekly analytics
9. Monthly analytics
10. Profile/goals page

### The dashboard should show
- Calories consumed vs target
- Remaining calories
- Protein, carbs, fat progress
- Water tracker
- Today's meal cards
- AI insight card
- Floating upload button

> The design should feel like a premium abstract nutrition app, inspired by clean mobile nutrition UI references, but original and more suitable for a webapp/PWA.
